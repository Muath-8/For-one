The ten rules

If you read nothing else. Each one is the compressed form of a page below, and each has a check in CI, a job in Inngest or a role in the admin behind it.

Fakes by defaultNobody calls a real vendor from a laptop unless they are working on that vendor. Every fake call is still priced, so you see the cost of a change before it runs for real.
Prompts are codeA file, a version, an eval run, a reviewer who is not the author. There is no prompt editor in the admin and there will not be one.
Synthetic learners everywhereDev, staging, cassettes, canaries and load tests use invented people. Real learners live in prod and nowhere else.
Learner text stays homeIds and enums may travel to Inngest, Sentry, Slack and the logs. Names, transcripts, facts and audio never do. Prompts reach Langfuse only with the opt-in.
Every look is loggedA human reading learner content writes a reason the learner can read in their own export.
Every promise is verified by a second jobDeletion windows are re-checked daily by code that does not share the doer's bugs.
Every vendor call is a priced rowThrough the middleware, on the cost page, with a fallback and a degrade path in vendors.yaml.
A deploy never cuts a callDrain then replace, outside the drop window, inside the release window, after a canary, with one human name on it.
Every alert has a runbook, every runbook has a switchIf a fix needs SQL at 05:40, the runbook gets an admin action instead.
Green on day oneCI, Terraform, the fakes and the first eval baseline exist before the first feature lands.

The path of a change

From a laptop to a learner's morning. Teal boxes are automated gates; the amber box is the only place a human name is required. The eval gate runs only when the diff touches something a model reads, and prints its cost before it spends it.

Three environments

No fourth. Backend preview environments were rejected for cost; a PR that needs a running backend is tested on staging under a Slack lock. Staging is stopped when idle, which saves about $200 a month.

Where learner data may go

The product holds a person's voice and the facts of their life. The home region holds everything at rest; the EU tools hold pointers; the model and voice vendors see only what their role needs, in transit, under a signed DPA. A laptop never holds any of it.

What the guard does with it

At 80% of the daily cap the system enters conserve (teacher to Sonnet batch, rewrites capped, host to Haiku, canaries skipped). At 100% it enters halt: queued episodes finish, no new on-demand generation except return episodes, calls are never cut, notes and claims are never degraded. The stop line at $1.00 pages Muath and opens a 48-hour window for a costed plan. It never stops service.

What the learner sees

Nothing. No cost, no "heavy user" message, no throttle text. The allowance is the only learner-facing limit and it is a product rule, not a cost rule. Every vendor call is one row in vendor_calls, priced from a dated price book, reconciled monthly against each vendor's invoice.

The ten pages

Each page is a Markdown file in engineering/, written against the nine architecture documents, concept v2 and the decisions of 23 October. The line under each title is the rule it carries that the architecture did not already state.

01

Repository layout

One monorepo, four deployables (web, api, workflows, call-worker), eight packages, one Python image with three entrypoints, naming rules, and where every prompt lives as a versioned file.

CarriesLanguage packages are per target language (packages/languages/en/) with learner-language UI strings separate, because there is no launch country any more.
02

Local development

A full day of the product on a laptop in under an hour: docker compose, idempotent seeds with three synthetic learners, the fake vendors and how to record a cassette, every environment variable with its owner.

CarriesFake calls still write priced vendor_calls rows, so the cost page works in dev.
03

Environments and deployment

dev, staging, prod; Terraform with an S3 backend; Secrets Manager injected by task role; GitHub OIDC; the home region question; the release window, freezes, rollback, expand-then-contract migrations, and the drained call-worker replacement.

CarriesNo long-lived AWS key exists for a human or for CI.
04

CI and CD

Four workflows, the checks on every PR, the eval gate that runs by diff and prints its cost, Vercel previews on staging, branch protection, the nightly, and the seven-step release.

CarriesA PR's eval gate may not spend more than $25 without a label and a reviewer's yes.
05

Testing strategy

Five layers: unit, contract, end to end, audio and voice, model-output evals. The simulated caller, the 50 scripted calls, golden sets seeded from Milestone 0, and the plan to port the coverage checker into the fitter.

CarriesA recognizer is gated on error-preservation rate before word error rate, because speech-to-text smooths learner errors.
06

Observability and on-call

Postgres as the metrics store, alerts as SQL with runbook links, the cost-per-session dashboard defined line by line, the six P1 families that ring a phone, the on-call rota for two people, and blameless postmortems.

CarriesA postmortem that produces only "be more careful" is sent back.
07

Vendor accounts and cost controls

The 25 accounts and who opens them, keys per environment and per engineer, the vendor-side retention switches, spend caps, spend modes, the stop line, the risk calendar and the monthly reconciliation.

CarriesOur cap is always lower than the vendor's cap, so ours fires first.
08

Coding standards and review

Python and TypeScript rules enforced by Ruff, Pyright and ESLint; PR shape; the ten rules for prompt changes; the nine things a reviewer checks in this product, laws first.

CarriesA model change is a prompt change and runs the same suites.
09

Data handling

Seven data classes, the promises the code keeps with their windows and verifying jobs, what engineers may look at without asking, with a reason, and never; where data may go; consent; fixtures; research use; incidents.

CarriesMilestone 0 fixtures beyond the 30 clips stay out of the public repository until counsel confirms the consent.
10

Definition of done

Checklists for a story, a prompt change, a release, and the build itself on 22 December.

CarriesA story without a kill switch is not done.
